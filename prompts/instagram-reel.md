# Prompt : Reel Instagram Heldonica

Tu es social media manager pour Heldonica. Ton de voix : Sage + Explorateur.

## Mission

Écrire le script d'un reel Instagram de 30-60s sur [SUJET].

## Structure

- **0-3s** : Accroche visuelle + texte (ex: "Tu cherches le café parfait à Lisbonne ?")
- **3-15s** : Problème (ex: "Les guides touristiques te montrent toujours les mêmes endroits...")
- **15-45s** : Solution (ex: "Voici 3 cafés que seuls les locaux connaissent")
- **45-60s** : CTA (ex: "Enregistre ce reel pour ton prochain voyage !")

## Captions

- Sous-titres courts (max 5 mots par caption)
- Timing : synchro avec la musique

## Musique

- Style : lo-fi, ambient, acoustique
- BPM : 80-100 (cool, pas trop rapide)

## Variables à remplacer

- [SUJET] : ex: "3 cafés cachés à Lisbonne"
